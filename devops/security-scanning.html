Security Scanning

SAST, container scanning, dependency audits, and secret detection — shift security left.

What is "Shifting Left"?

Traditionally, security teams checked the final product before release. "Shifting left" means catching security issues earlier — in the developer's editor, in the CI pipeline, before code merges. It's much cheaper to fix a vulnerability at PR review than after a breach.

Security Gates in CI/CD
📝 Code Written
IDE lint + secret detection (pre-commit)
🔀 Pull Request
SAST scan + dependency audit (CI)
🐳 Docker Build
Container image scan (Trivy / Snyk)
☸️ Deploy to Staging
DAST scan against running app (OWASP ZAP)
🚀 Production
Runtime monitoring + policy enforcement

Container Image Scanning — Trivy

Trivy scans Docker images for known CVEs (Common Vulnerabilities and Exposures) in OS packages and language dependencies.

# Install Trivy
brew install trivy  # macOS
# or: curl -sfL https://raw.githubusercontent.com/aquasecurity/trivy/main/contrib/install.sh | sh

# Scan a local image
trivy image myapp-backend:latest

# Scan with severity filter (fail CI on CRITICAL)
trivy image --exit-code 1 --severity CRITICAL myapp-backend:latest

# Scan in GitHub Actions
- name: Scan image for vulnerabilities
  uses: aquasecurity/trivy-action@master
  with:
    image-ref: myappacr.azurecr.io/backend:${{ github.sha }}
    exit-code: 1
    severity: CRITICAL,HIGH

Dependency Auditing

# .NET — check for known vulnerable NuGet packages
dotnet list package --vulnerable

# Node.js / React
npm audit
npm audit --audit-level=high   # fail on high/critical only

# In GitHub Actions (Node)
- name: Audit dependencies
  run: npm audit --audit-level=high

Secret Detection — GitLeaks

GitLeaks scans your git history for accidentally committed secrets (API keys, passwords, tokens).

# Install
brew install gitleaks

# Scan current repo
gitleaks detect --source . --verbose

# Scan git history
gitleaks detect --source . --log-opts="HEAD~10..HEAD"

# Use as pre-commit hook (.pre-commit-config.yaml)
repos:
- repo: https://github.com/gitleaks/gitleaks
  rev: v8.18.0
  hooks:
  - id: gitleaks

SAST — Static Analysis

# .NET — use Roslyn analyzers (built-in)
# Add to your .csproj:
<ItemGroup>
  <PackageReference Include="Microsoft.CodeAnalysis.NetAnalyzers" Version="8.*" />
  <PackageReference Include="SecurityCodeScan.VS2019" Version="5.*" />
</ItemGroup>

# JavaScript / TypeScript — ESLint with security plugin
npm install --save-dev eslint-plugin-security
# Add to .eslintrc:
{ "plugins": ["security"], "extends": ["plugin:security/recommended"] }

Kubernetes Policy Enforcement

# Install OPA Gatekeeper
kubectl apply -f https://raw.githubusercontent.com/open-policy-agent/gatekeeper/release-3.15/deploy/gatekeeper.yaml

# Example: Block containers running as root
apiVersion: constraints.gatekeeper.sh/v1beta1
kind: K8sPSPAllowPrivilegeEscalationContainer
metadata:
  name: no-root-containers
spec:
  match:
    kinds:
    - apiGroups: ["apps"]
      kinds: ["Deployment"]
  parameters:
    allowPrivilegeEscalation: false
