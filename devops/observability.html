Observability

Metrics, logs, and traces — Prometheus, Grafana, and Loki for Kubernetes.

The Three Pillars of Observability

Metrics are numbers over time (CPU usage, request count, error rate). Think of them as a speedometer. Logs are text records of what happened ("User 123 logged in at 14:32"). Traces follow a single request through multiple services to find where it slowed down. You need all three to understand a production system.

Observability Stack
📊 Prometheus
Scrapes metrics from pods every 15s
📝 Loki
Aggregates pod logs
🔍 Tempo
Distributed traces
📈 Grafana
Single UI — dashboards, alerts, log search, trace viewer

Install Prometheus + Grafana (kube-prometheus-stack)

helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update

helm install monitoring prometheus-community/kube-prometheus-stack \
  --namespace monitoring \
  --create-namespace \
  --set grafana.adminPassword=admin123 \
  --set prometheus.prometheusSpec.retention=7d

# Verify pods
kubectl get pods -n monitoring

Access Grafana

# Port-forward Grafana
kubectl port-forward svc/monitoring-grafana -n monitoring 3000:80

# Open http://localhost:3000
# Username: admin
# Password: admin123

Expose App Metrics from .NET 8

# Install prometheus-net NuGet package
dotnet add package prometheus-net.AspNetCore
// Program.cs — expose /metrics endpoint
using Prometheus;

app.UseHttpMetrics();      // track HTTP request metrics
app.MapMetrics();          // expose at /metrics

Annotate Pods for Prometheus Scraping

# In your Deployment spec:
template:
  metadata:
    annotations:
      prometheus.io/scrape: "true"
      prometheus.io/port: "8080"
      prometheus.io/path: "/metrics"

Essential PromQL Queries

# Request rate (requests/second, last 5 min)
rate(http_requests_total[5m])

# Error rate (% of 5xx responses)
rate(http_requests_total{status=~"5.."}[5m]) / rate(http_requests_total[5m]) * 100

# Pod memory usage (MiB)
container_memory_working_set_bytes{namespace="myapp"} / 1024 / 1024

# Pod CPU usage (cores)
rate(container_cpu_usage_seconds_total{namespace="myapp"}[5m])

Install Loki for Logs

helm repo add grafana https://grafana.github.io/helm-charts
helm install loki grafana/loki-stack \
  --namespace monitoring \
  --set grafana.enabled=false \
  --set promtail.enabled=true

# In Grafana, add Loki data source:
# URL: http://loki:3100
