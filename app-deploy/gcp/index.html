Deploy to GCP GKE

Google Cloud

End-to-end guide: deploy a React + .NET 8 app to Google Kubernetes Engine with CI/CD, SSL, and monitoring.

What You'll Build

You'll deploy a production-ready web application to Google Cloud. Your React frontend will be served globally via Cloud CDN, your .NET 8 API will run in GKE, and your data will live in Cloud SQL (PostgreSQL). Cloud Build will deploy new versions automatically on every git push.

Target Architecture — GCP GKE
👤 User / Browser
🌐 Cloud DNS + Cloud CDN
Global routing + React static files
⚖️ Cloud Load Balancing
HTTPS Ingress — SSL termination
GCP VPC — us-central1 (Private Subnet)
⚛️ React Pod
Nginx container
⚙️ .NET API Pod
ASP.NET Core 8
📦 Artifact Registry
Container images
🗄️ Cloud SQL
PostgreSQL
📦 Cloud Storage
User uploads
🔑 Secret Manager
Secrets at runtime
