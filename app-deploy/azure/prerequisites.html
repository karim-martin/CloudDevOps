Prerequisites

Tools and accounts you need before starting the Azure AKS deployment guide.

First Time Setting Up?

This page walks through every tool you need. Install them in order — each one builds on the previous. The whole setup takes about 20 minutes.

Required Accounts

☁️

Azure Account

Free account at portal.azure.com — $200 credit for 30 days + 12 months free services.

🐙

GitHub Account

For storing your code and triggering Azure Pipelines deployments.

🔧

Azure DevOps

Free at dev.azure.com — Azure Pipelines lives here (5 free parallel jobs).

Install Azure CLI

# macOS
brew install azure-cli

# Ubuntu / Debian
curl -sL https://aka.ms/InstallAzureCLIDeb | sudo bash

# Windows (PowerShell)
winget install Microsoft.AzureCLI

# Verify
az --version

# Log in
az login

Install kubectl

# macOS
brew install kubectl

# Linux
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
chmod +x kubectl && sudo mv kubectl /usr/local/bin/

# Verify
kubectl version --client

Install Helm

# macOS / Linux
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash

# Verify
helm version

Install Terraform

# macOS
brew install terraform

# Linux
wget -O- https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
sudo apt update && sudo apt install terraform

# Verify
terraform --version

Install Docker

# Download Docker Desktop from docker.com/products/docker-desktop
# Or on Linux:
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
newgrp docker

# Verify
docker --version

Verify Everything

az --version       # Azure CLI
kubectl version --client
helm version
terraform --version
docker --version
Set Your Default Subscription
# List subscriptions
az account list --output table

# Set default
az account set --subscription "My Subscription Name"

# Verify
az account show
