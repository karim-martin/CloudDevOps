Monitoring

Azure Monitor, Container Insights, and Log Analytics for full observability on AKS.

What to Monitor

You need three things: metrics (CPU, memory, request rate — numbers over time), logs (what each pod printed to stdout), and alerts (notify your team when something goes wrong). Azure Monitor provides all three.

Container Insights (Already Enabled via Terraform)

When you added oms_agent { log_analytics_workspace_id = ... } to your AKS Terraform, Container Insights was automatically enabled. In the Azure portal, navigate to your AKS cluster → Monitoring → Insights.

Key Log Analytics Queries (KQL)

# Pod restart count last 24h
KubePodInventory
| where TimeGenerated > ago(24h)
| where Namespace == "myapp"
| summarize Restarts=sum(PodRestartCount) by PodUid, Name

# Backend HTTP 5xx errors
ContainerLog
| where TimeGenerated > ago(1h)
| where ContainerName == "backend"
| where LogEntry contains "500"
| project TimeGenerated, LogEntry

# Node CPU usage
Perf
| where ObjectName == "K8SNode"
| where CounterName == "cpuUsageNanoCores"
| summarize avg(CounterValue) by Computer, bin(TimeGenerated, 5m)

Azure Monitor Alert

# Terraform — alert when CPU exceeds 80%
resource "azurerm_monitor_metric_alert" "cpu_alert" {
  name                = "aks-high-cpu"
  resource_group_name = azurerm_resource_group.main.name
  scopes              = [azurerm_kubernetes_cluster.main.id]
  description         = "AKS node CPU > 80%"
  severity            = 2
  frequency           = "PT5M"
  window_size         = "PT15M"

  criteria {
    metric_namespace = "Microsoft.ContainerService/managedClusters"
    metric_name      = "node_cpu_usage_percentage"
    aggregation      = "Average"
    operator         = "GreaterThan"
    threshold        = 80
  }

  action {
    action_group_id = azurerm_monitor_action_group.ops.id
  }
}

resource "azurerm_monitor_action_group" "ops" {
  name                = "ops-team"
  resource_group_name = azurerm_resource_group.main.name
  short_name          = "ops"

  email_receiver {
    name          = "ops-email"
    email_address = "ops@myapp.com"
  }
}
Application Insights for APM

For request tracing inside your .NET app (slow queries, exceptions, request counts), add Azure Application Insights: builder.Services.AddApplicationInsightsTelemetry();. It correlates frontend and backend requests into end-to-end traces.
