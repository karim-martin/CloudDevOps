Workload Identity

AKS pods authenticate to Azure services using Managed Identity — zero hardcoded credentials.

Why Workload Identity?

Traditional apps put passwords in config files. If someone reads the config, they have your database password. Workload Identity works like a building access badge — the pod proves its identity to Azure (via OIDC), and Azure grants access to the right resources. No passwords ever leave the system.

Workload Identity Flow
📦 .NET Pod
Requests token from AKS OIDC
🔑 AKS OIDC Issuer
Issues JWT token for Service Account
🆔 Entra ID (Azure AD)
Validates token → grants Managed Identity
🔐 Key Vault / Azure SQL
Grants access based on RBAC role

Step 1 — Create Managed Identity

# Create a User-Assigned Managed Identity
az identity create \
  --name myapp-identity \
  --resource-group myapp-rg

# Get the identity details
IDENTITY_CLIENT_ID=$(az identity show \
  --name myapp-identity \
  --resource-group myapp-rg \
  --query clientId -o tsv)

IDENTITY_OBJECT_ID=$(az identity show \
  --name myapp-identity \
  --resource-group myapp-rg \
  --query principalId -o tsv)

Step 2 — Get AKS OIDC Issuer

AKS_OIDC_ISSUER=$(az aks show \
  --name myapp-aks \
  --resource-group myapp-rg \
  --query "oidcIssuerProfile.issuerUrl" -o tsv)

Step 3 — Create Federated Credential

az identity federated-credential create \
  --name myapp-fedcred \
  --identity-name myapp-identity \
  --resource-group myapp-rg \
  --issuer "$AKS_OIDC_ISSUER" \
  --subject "system:serviceaccount:myapp:backend-sa" \
  --audience api://AzureADTokenExchange

Step 4 — Create Kubernetes Service Account

# backend-sa.yaml
apiVersion: v1
kind: ServiceAccount
metadata:
  name: backend-sa
  namespace: myapp
  annotations:
    azure.workload.identity/client-id: "<IDENTITY_CLIENT_ID>"
kubectl apply -f backend-sa.yaml

Step 5 — Assign RBAC Role

# Grant the identity access to Key Vault secrets
az role assignment create \
  --assignee-object-id "$IDENTITY_OBJECT_ID" \
  --role "Key Vault Secrets User" \
  --scope "/subscriptions/<sub-id>/resourceGroups/myapp-rg/providers/Microsoft.KeyVault/vaults/myapp-kv"
