VPC & Networking

Provision a multi-AZ VPC with public, private, and database subnets ready for EKS.

What is a VPC?

A VPC (Virtual Private Cloud) is your own isolated network inside AWS. You pick the IP range, split it into subnets across Availability Zones, and decide which subnets can reach the internet. EKS nodes live in private subnets; load balancers live in public subnets.

Network Layout

  • VPC CIDR: 10.0.0.0/16 — ~65k addresses across 3 AZs.
  • Public subnets: 10.0.1.0/24, 10.0.2.0/24, 10.0.3.0/24 — for ALBs and NAT gateways.
  • Private subnets: 10.0.11.0/24, 10.0.12.0/24, 10.0.13.0/24 — for EKS worker nodes and pods.
  • Database subnets: 10.0.21.0/24, 10.0.22.0/24, 10.0.23.0/24 — isolated for RDS.

Terraform VPC Module

# main.tf
terraform {
  required_providers {
    aws = { source = "hashicorp/aws", version = "~> 5.0" }
  }
}

provider "aws" {
  region = "us-east-1"
}

module "vpc" {
  source  = "terraform-aws-modules/vpc/aws"
  version = "~> 5.0"

  name = "myapp-vpc"
  cidr = "10.0.0.0/16"

  azs              = ["us-east-1a", "us-east-1b", "us-east-1c"]
  public_subnets   = ["10.0.1.0/24",  "10.0.2.0/24",  "10.0.3.0/24"]
  private_subnets  = ["10.0.11.0/24", "10.0.12.0/24", "10.0.13.0/24"]
  database_subnets = ["10.0.21.0/24", "10.0.22.0/24", "10.0.23.0/24"]

  enable_nat_gateway     = true
  single_nat_gateway     = false
  one_nat_gateway_per_az = true
  enable_dns_hostnames   = true

  # Required so EKS can discover subnets for load balancers
  public_subnet_tags  = { "kubernetes.io/role/elb"          = "1" }
  private_subnet_tags = { "kubernetes.io/role/internal-elb" = "1" }

  tags = { Environment = "production", Project = "myapp" }
}

output "vpc_id"              { value = module.vpc.vpc_id }
output "public_subnet_ids"   { value = module.vpc.public_subnets }
output "private_subnet_ids"  { value = module.vpc.private_subnets }
output "database_subnet_ids" { value = module.vpc.database_subnets }

Apply

terraform init
terraform plan
terraform apply   # ~5 minutes (NAT gateways take the longest)
NAT Gateway Cost

One NAT gateway per AZ costs roughly $100/mo for three AZs before data transfer. For non-prod environments, set single_nat_gateway = true and cut this to ~$33/mo — at the cost of cross-AZ traffic if that one AZ goes down.
