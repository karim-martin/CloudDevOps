EKS Cluster

Create a managed Kubernetes cluster with managed node groups and IRSA enabled.

What is EKS?

EKS (Elastic Kubernetes Service) runs the Kubernetes control plane for you across multiple AZs. You only manage the worker nodes (EC2 instances or Fargate pods). Amazon handles upgrades, patching, and control-plane HA.

Create EKS with Terraform

# eks.tf
module "eks" {
  source  = "terraform-aws-modules/eks/aws"
  version = "~> 20.0"

  cluster_name    = "myapp-cluster"
  cluster_version = "1.29"

  vpc_id                   = module.vpc.vpc_id
  subnet_ids               = module.vpc.private_subnets
  control_plane_subnet_ids = module.vpc.private_subnets

  cluster_endpoint_public_access = true

  # Required for IRSA
  enable_irsa = true

  eks_managed_node_groups = {
    system = {
      min_size     = 2
      max_size     = 4
      desired_size = 2

      instance_types = ["t3.medium"]
      capacity_type  = "ON_DEMAND"
      labels         = { role = "system" }
    }

    workloads = {
      min_size     = 2
      max_size     = 10
      desired_size = 3

      instance_types = ["t3.large"]
      capacity_type  = "ON_DEMAND"
      labels         = { role = "workloads" }
    }
  }

  # Add-ons: use the latest compatible versions
  cluster_addons = {
    coredns                = { most_recent = true }
    kube-proxy             = { most_recent = true }
    vpc-cni                = { most_recent = true }
    aws-ebs-csi-driver     = { most_recent = true }
  }

  tags = { Environment = "production", Project = "myapp" }
}

output "cluster_name"     { value = module.eks.cluster_name }
output "cluster_endpoint" { value = module.eks.cluster_endpoint }
output "oidc_provider_arn" { value = module.eks.oidc_provider_arn }

Connect kubectl

aws eks update-kubeconfig \
  --region us-east-1 \
  --name myapp-cluster

# Verify
kubectl get nodes
kubectl get pods --all-namespaces

Install AWS Load Balancer Controller

# Needed to provision ALBs from Ingress resources
helm repo add eks https://aws.github.io/eks-charts
helm repo update

helm install aws-load-balancer-controller eks/aws-load-balancer-controller \
  -n kube-system \
  --set clusterName=myapp-cluster \
  --set serviceAccount.create=true \
  --set serviceAccount.name=aws-load-balancer-controller
Separate System and Workload Node Groups

The system node group runs cluster add-ons (CoreDNS, metrics-server, controllers). The workloads node group runs your app pods. This lets you scale or upgrade them independently.
