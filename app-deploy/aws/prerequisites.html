AWS Prerequisites

AWS

Tools and accounts needed before deploying to AWS EKS.

Required Accounts

☁️

AWS Account

Create a free account at aws.amazon.com. New accounts get a 12-month free tier. Enable MFA on the root account immediately.

🐙

GitHub Account

Required for the CI/CD pipeline. Your React and .NET 8 source code should be in a GitHub repository.

🌐

Domain Name (optional)

Register a domain in Route 53 or bring your own. Required for HTTPS with a custom domain. Can be added later.

Required CLI Tools

# 1. AWS CLI v2
# macOS:
brew install awscli
# Linux:
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip && sudo ./aws/install

aws --version  # aws-cli/2.x.x

# 2. eksctl — EKS cluster management
# macOS:
brew tap weaveworks/tap
brew install weaveworks/tap/eksctl
# Linux:
ARCH=amd64
PLATFORM=$(uname -s)_$ARCH
curl -sLO "https://github.com/eksctl-io/eksctl/releases/latest/download/eksctl_$PLATFORM.tar.gz"
tar -xzf eksctl_$PLATFORM.tar.gz -C /tmp && sudo mv /tmp/eksctl /usr/local/bin

eksctl version

# 3. kubectl
# macOS:
brew install kubectl
# Linux:
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
chmod +x kubectl && sudo mv kubectl /usr/local/bin/

kubectl version --client

# 4. Helm
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
helm version

# 5. Terraform
# macOS:
brew tap hashicorp/tap && brew install hashicorp/tap/terraform
# Linux: https://developer.hashicorp.com/terraform/install
terraform --version

# 6. Docker
# https://docs.docker.com/get-docker/
docker --version

Configure AWS CLI

# Create an IAM user with programmatic access (least privilege)
# Never use root account credentials here

aws configure
# AWS Access Key ID: AKIA...
# AWS Secret Access Key: ...
# Default region name: us-east-1
# Default output format: json

# Verify
aws sts get-caller-identity

Application Requirements

This guide deploys a React + .NET 8 app. Your app needs:

  • React frontend — build with npm run build, serve with Nginx or serve-static
  • .NET 8 backend — Web API project that reads config from environment variables or AWS Secrets Manager
  • Dockerfiles — one per service (we'll create these in the Deployment section)
  • Health check endpoints — GET /health returning HTTP 200 for Kubernetes liveness probes
