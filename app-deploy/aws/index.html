Deploy to AWS EKS

AWS

End-to-end guide for deploying React + .NET 8 to Amazon EKS.

This guide walks you through deploying a production-ready React + .NET 8 application to Amazon Elastic Kubernetes Service (EKS) — the industry standard for running Kubernetes on AWS.

What You'll Build

  • EKS Cluster — Managed Kubernetes with Managed Node Groups across 3 AZs
  • React Frontend — 3 replicas, served via ALB with CloudFront CDN
  • .NET 8 Backend — 3 replicas with Horizontal Pod Autoscaler
  • RDS PostgreSQL — Multi-AZ managed database in private subnets
  • S3 — Object storage for file uploads
  • ACM SSL — AWS-managed certificates with auto-renewal
  • IRSA — Keyless authentication for pods via IAM Roles for Service Accounts
  • CI/CD — GitHub Actions pushing to ECR and deploying to EKS

Learning Path

1. Foundation

AWS account setup, IAM configuration, and VPC networking with public/private subnets.

2. Infrastructure

EKS cluster, RDS PostgreSQL database, and S3 storage using Terraform.

3. Deployment

Dockerfiles, Kubernetes manifests, and deploying both services to EKS.

4. Networking

AWS Load Balancer Controller, ALB Ingress, and ACM SSL certificates.

5. Security

IRSA for keyless auth, Secrets Manager integration, and WAF protection.

6. Operations

GitHub Actions CI/CD, HPA autoscaling, and CloudWatch monitoring.

Cost Estimate

Running this setup on AWS costs approximately $8–20/day for a development cluster (EKS: $0.10/hr, 2× t3.medium nodes: ~$0.094/hr, RDS t3.micro: ~$0.025/hr). Use Spot Instances for non-prod to save 70%. Delete resources when done, or use the AWS Free Tier where available.
