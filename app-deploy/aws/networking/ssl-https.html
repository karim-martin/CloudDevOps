SSL/HTTPS on AWS

AWS

Free SSL certificates with AWS Certificate Manager and ACM auto-renewal.

Request ACM Certificate

# Request a free SSL certificate
aws acm request-certificate \
  --domain-name myapp.example.com \
  --subject-alternative-names "*.myapp.example.com" \
  --validation-method DNS \
  --region us-east-1

# Get the certificate ARN
aws acm list-certificates --region us-east-1

# Get DNS validation records to add to Route 53
aws acm describe-certificate \
  --certificate-arn arn:aws:acm:us-east-1:123:certificate/abc \
  --query "Certificate.DomainValidationOptions"

Add DNS Validation Record

# Add CNAME record to Route 53 for certificate validation
aws route53 change-resource-record-sets \
  --hosted-zone-id Z1234567890 \
  --change-batch '{
    "Changes": [{
      "Action": "UPSERT",
      "ResourceRecordSet": {
        "Name": "_abc123.myapp.example.com",
        "Type": "CNAME",
        "TTL": 300,
        "ResourceRecords": [{"Value": "_xyz.acm-validations.aws."}]
      }
    }]
  }'

# Wait for validation (2-10 minutes)
aws acm wait certificate-validated \
  --certificate-arn arn:aws:acm:us-east-1:123:certificate/abc
echo "Certificate validated!"

Point Domain to ALB

# Get ALB DNS name from Ingress
ALB_DNS=$(kubectl -n production get ingress myapp-ingress -o jsonpath='{.status.loadBalancer.ingress[0].hostname}')

# Create Route 53 alias record
aws route53 change-resource-record-sets \
  --hosted-zone-id Z1234567890 \
  --change-batch '{
    "Changes": [{
      "Action": "UPSERT",
      "ResourceRecordSet": {
        "Name": "myapp.example.com",
        "Type": "A",
        "AliasTarget": {
          "DNSName": "'$ALB_DNS'",
          "EvaluateTargetHealth": true,
          "HostedZoneId": "Z35SXDOTRQ7X7K"
        }
      }
    }]
  }'
ACM Auto-Renewal

ACM certificates renew automatically 60 days before expiry — no manual action needed. This is a big advantage over Let's Encrypt (which requires certbot cron jobs).
