Containerize

Write Dockerfiles for React and .NET 8. Build and push images to ECR.

React Frontend

Kubernetes Deployment and Service for the React frontend pod.

.NET 8 Backend

Kubernetes Deployment with config from Secrets Manager via IRSA.

ECR Setup

aws ecr create-repository --repository-name myapp/frontend --region us-east-1
aws ecr create-repository --repository-name myapp/backend --region us-east-1

# Authenticate Docker to ECR
aws ecr get-login-password --region us-east-1 | \
  docker login --username AWS --password-stdin 123456789.dkr.ecr.us-east-1.amazonaws.com

Configure kubectl

aws eks update-kubeconfig --name myapp-cluster --region us-east-1
kubectl get nodes  # Should show 3 Ready nodes
kubectl create namespace production
