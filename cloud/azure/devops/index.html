Azure DevOps

Azure

CI/CD with Azure Pipelines and the full Azure DevOps suite.

Azure DevOps = Microsoft's All-in-One DevOps Platform

Azure DevOps is a complete platform including: Boards (Kanban/Scrum project tracking), Repos (Git repositories), Pipelines (CI/CD), Test Plans (manual and automated testing), and Artifacts (package feeds for npm, NuGet, Maven). You can use it as a complete GitHub+Jenkins replacement, or just use Azure Pipelines with GitHub repos.

Azure DevOps Pipeline Flow
👨‍💻 Developer
git push
📋 Azure Pipelines
Triggered automatically
🔨 Build & Test
dotnet build, dotnet test
→
📦 Push to ACR
Docker image pushed
→
🚀 Deploy to AKS
kubectl / Helm
