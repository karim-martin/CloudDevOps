Azure Monitor

Azure

Unified observability — metrics, alerts, and Container Insights for AKS.

Azure Monitor Watches Everything Automatically

Azure Monitor automatically collects metrics from Azure resources — your AKS cluster's CPU, your SQL Database's DTU consumption, your App Gateway's request rate. You define Alerts that trigger when metrics cross thresholds, sending notifications to email, PagerDuty, or Teams. Workbooks let you build rich interactive dashboards. Container Insights provides pod-level metrics for AKS.

Enable Container Insights for AKS

# Enable when creating the cluster
az aks create \
  --name myapp-cluster \
  --resource-group myapp-rg \
  --enable-addons monitoring \
  --workspace-resource-id /subscriptions/{sub}/resourceGroups/myapp-rg/providers/Microsoft.OperationalInsights/workspaces/myapp-workspace

# Or enable on existing cluster
az aks enable-addons \
  --addons monitoring \
  --name myapp-cluster \
  --resource-group myapp-rg

Create an Alert (Terraform)

resource "azurerm_monitor_metric_alert" "cpu_alert" {
  name                = "aks-high-cpu"
  resource_group_name = azurerm_resource_group.main.name
  scopes              = [azurerm_kubernetes_cluster.main.id]
  description         = "AKS CPU exceeds 80%"
  severity            = 2  # Warning

  criteria {
    metric_namespace = "Microsoft.ContainerService/managedClusters"
    metric_name      = "node_cpu_usage_percentage"
    aggregation      = "Average"
    operator         = "GreaterThan"
    threshold        = 80
  }

  action {
    action_group_id = azurerm_monitor_action_group.main.id
  }

  frequency   = "PT5M"
  window_size = "PT15M"
}

Application Insights for APM

// Program.cs — add Application Insights
builder.Services.AddApplicationInsightsTelemetry(
    builder.Configuration["ApplicationInsights:InstrumentationKey"]);

Application Insights automatically tracks: HTTP request rates and durations, dependency calls (SQL, HTTP, Redis), exceptions, custom events, and user sessions.
