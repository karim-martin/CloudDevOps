Azure Observability

Azure

Azure Monitor and Log Analytics — metrics, logs, and alerts.

Know What's Happening in Your Azure App

Azure Monitor is the umbrella service for all observability in Azure. It collects metrics from all Azure resources automatically. Log Analytics is the log storage and query engine (using KQL — Kusto Query Language). Application Insights gives you end-to-end APM (Application Performance Monitoring) including distributed tracing, dependency tracking, and user sessions.

Azure Monitor

Unified monitoring platform. Metrics, alerts, autoscale rules, dashboards, and Container Insights for AKS.

Log Analytics

Centralized log storage with KQL queries. Used by Monitor, Defender, and Sentinel for security and operational analysis.
