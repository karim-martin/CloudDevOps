Azure Log Analytics

Azure

Centralized log storage and analysis with Kusto Query Language (KQL).

Log Analytics = SQL for Your Logs

Log Analytics is where all Azure logs go — AKS pod logs, Azure SQL audit logs, Application Insights traces, Defender security alerts. You query them using KQL (Kusto Query Language) — a powerful language similar to SQL but designed for log analysis. You can filter, aggregate, join, and visualize log data to diagnose incidents, track user behavior, and monitor security.

KQL Query Examples

# Find all errors in the last hour
ContainerLog
| where LogEntry contains "ERROR"
| where TimeGenerated > ago(1h)
| project TimeGenerated, PodName, ContainerName, LogEntry
| order by TimeGenerated desc

# Count errors per pod per minute
ContainerLog
| where LogEntry contains "ERROR"
| summarize ErrorCount = count() by bin(TimeGenerated, 1m), PodName
| order by TimeGenerated asc

# AKS pod CPU usage
KubePodInventory
| where TimeGenerated > ago(1h)
| join kind=inner (Perf
    | where ObjectName == "K8SContainer"
    | where CounterName == "cpuUsageNanoCores"
    | summarize AvgCPU = avg(CounterValue) by InstanceName, bin(TimeGenerated, 5m)
  ) on InstanceName
| project TimeGenerated, PodName, AvgCPU

Create Log Analytics Workspace

# Create workspace
az monitor log-analytics workspace create \
  --resource-group myapp-rg \
  --workspace-name myapp-workspace \
  --location eastus \
  --retention-time 30  # days

Ship Container Logs from AKS

When Container Insights is enabled on AKS, logs from all pods automatically flow to Log Analytics via the Azure Monitor Agent (DaemonSet). No manual log shipping configuration needed.

Log Retention Costs

Log Analytics charges ~$2.76/GB ingested and $0.10/GB archived beyond 90 days. Set retention policies per table to control costs. For AKS, debug-level logs can be very verbose — consider filtering before shipping.
