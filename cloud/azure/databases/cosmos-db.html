Azure Cosmos DB

Azure

Globally distributed, multi-model NoSQL database with 99.999% availability.

Cosmos DB Speaks Many Languages

Cosmos DB is unique in that it supports multiple APIs — you can use the MongoDB API, Cassandra API, Gremlin (graph), or Core (SQL) API. This means you can migrate existing MongoDB or Cassandra apps without rewriting them. All APIs store data in the same underlying engine with the same global distribution and single-digit millisecond latency.

Core Concepts

🌍

Global Distribution

Replicate data to any Azure region with one click. Multi-region writes mean any region can accept writes — no primary/replica bottleneck.

⚡

<10ms Latency

Indexed writes and reads at single-digit millisecond latency at the 99th percentile — regardless of scale.

🔧

Multiple APIs

NoSQL (SQL-like), MongoDB, Cassandra, Gremlin (graph), Table. Pick the API that matches your existing code.

📈

Autoscale

Set max RUs (Request Units). Cosmos DB scales capacity up and down automatically based on actual traffic. Pay only for what you use.

Create and Query (NoSQL API)

az cosmosdb create \
  --name myapp-cosmos \
  --resource-group myapp-rg \
  --kind GlobalDocumentDB \
  --locations regionName=eastus failoverPriority=0

az cosmosdb sql database create \
  --account-name myapp-cosmos \
  --resource-group myapp-rg \
  --name myapp-db

az cosmosdb sql container create \
  --account-name myapp-cosmos \
  --resource-group myapp-rg \
  --database-name myapp-db \
  --name users \
  --partition-key-path /userId \
  --throughput 400
// .NET SDK
var client = new CosmosClient(endpoint, new DefaultAzureCredential());
var container = client.GetContainer("myapp-db", "users");

// Create item
await container.CreateItemAsync(new { id = "user-1", userId = "user-1", name = "Alice" });

// Query
var query = new QueryDefinition("SELECT * FROM c WHERE c.userId = @id")
    .WithParameter("@id", "user-1");
var iterator = container.GetItemQueryIterator<dynamic>(query);
