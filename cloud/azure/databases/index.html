Azure Databases

Azure

Managed database services — Azure SQL, Cosmos DB, and Azure Cache for Redis.

Azure Databases are Fully Managed

Like GCP and AWS, Azure manages database infrastructure — backups, patches, failover — automatically. Azure's database portfolio is especially strong for Microsoft-stack teams: Azure SQL is fully compatible with SQL Server, making migrations from on-prem trivial. Cosmos DB is Azure's globally distributed NoSQL offering supporting multiple APIs.

Azure SQL

Managed SQL Server. 100% compatible with on-prem SQL Server. Intelligent performance tuning and automatic backups.

Cosmos DB

Globally distributed multi-model NoSQL. Single-digit millisecond latency worldwide, 99.999% availability SLA.

Azure Cache for Redis

Managed Redis. Cache database results, store sessions, and accelerate read-heavy workloads.
