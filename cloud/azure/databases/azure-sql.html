Azure SQL

Azure

Managed SQL Server — intelligent, always up-to-date cloud database.

Azure SQL = SQL Server, Without the Server

Azure SQL Database is Microsoft's managed SQL Server in the cloud. It's 100% compatible with SQL Server — so if you have an on-prem SQL Server app, you can migrate it to Azure SQL with minimal code changes. Azure manages backups (point-in-time restore up to 35 days), patches, high availability (3 replicas by default on the Business Critical tier), and automatic scaling.

Create Azure SQL Database

# Create SQL Server
az sql server create \
  --name myapp-sqlserver \
  --resource-group myapp-rg \
  --location eastus \
  --admin-user adminuser \
  --admin-password "Str0ngP@ssw0rd!"

# Create database
az sql db create \
  --server myapp-sqlserver \
  --resource-group myapp-rg \
  --name myapp-db \
  --edition GeneralPurpose \
  --family Gen5 \
  --capacity 2 \
  --backup-storage-redundancy Zone

# Allow AKS subnet to connect (private endpoint preferred)
az sql server firewall-rule create \
  --server myapp-sqlserver \
  --resource-group myapp-rg \
  --name AllowAKS \
  --start-ip-address 10.0.11.0 \
  --end-ip-address 10.0.11.255

Connect from .NET

// Program.cs — retrieve connection string from Key Vault
var keyVaultUri = new Uri("https://myapp-vault.vault.azure.net/");
var credential = new DefaultAzureCredential();  // Workload Identity
var client = new SecretClient(keyVaultUri, credential);

var connString = (await client.GetSecretAsync("sql-connection-string")).Value.Value;
builder.Services.AddDbContext<AppDbContext>(options =>
    options.UseSqlServer(connString));
