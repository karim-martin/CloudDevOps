Azure Cache for Redis

Azure

Managed in-memory cache to accelerate your applications.

Redis Cache = Sub-Millisecond Data Access

Redis stores data in RAM (memory), not on disk. This makes it 100–1000× faster than a traditional database for reads. Azure Cache for Redis is the managed version — Azure handles replication, failover, patches, and monitoring. Common uses: cache database query results, store HTTP sessions across multiple app pods, implement rate limiting, and build real-time leaderboards.

Create Azure Cache for Redis

az redis create \
  --name myapp-cache \
  --resource-group myapp-rg \
  --location eastus \
  --sku Standard \
  --vm-size c1  # 1 GB cache, replication enabled

Session Storage in ASP.NET Core

// Program.cs
builder.Services.AddStackExchangeRedisCache(options => {
    options.Configuration = builder.Configuration["Redis:ConnectionString"];
    options.InstanceName = "myapp-";
});
builder.Services.AddSession(options => {
    options.IdleTimeout = TimeSpan.FromMinutes(30);
    options.Cookie.HttpOnly = true;
    options.Cookie.IsEssential = true;
});

// appsettings.json (retrieve from Key Vault in production)
{
  "Redis": {
    "ConnectionString": "myapp-cache.redis.cache.windows.net:6380,password=...,ssl=True"
  }
}
