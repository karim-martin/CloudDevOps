Azure DDoS Protection

Azure

Protect Azure resources from distributed denial-of-service attacks.

DDoS = Flooding Your App Until It Falls Over

A DDoS (Distributed Denial-of-Service) attack sends massive amounts of traffic to your application from thousands of machines simultaneously, overwhelming your servers. Azure's network infrastructure absorbs and mitigates most DDoS attacks automatically. DDoS Protection Basic is built into all Azure services at no cost. DDoS Protection Standard ($2,944/month) adds adaptive tuning, attack analytics, and a DDoS Rapid Response team.

WAF with Application Gateway

For Layer 7 (HTTP) attack protection, use Web Application Firewall on Application Gateway or Azure Front Door:

resource "azurerm_web_application_firewall_policy" "main" {
  name                = "myapp-waf-policy"
  resource_group_name = azurerm_resource_group.main.name
  location            = "eastus"

  policy_settings {
    enabled                     = true
    mode                        = "Prevention"
    request_body_check          = true
    file_upload_limit_in_mb     = 100
    max_request_body_size_in_kb = 128
  }

  managed_rules {
    managed_rule_set {
      type    = "OWASP"
      version = "3.2"
    }
  }
}
Front Door WAF is Usually Sufficient

For most applications, combining Azure Front Door (with WAF) and basic DDoS protection provides adequate security at reasonable cost. DDoS Standard is primarily for high-profile targets or compliance requirements.
