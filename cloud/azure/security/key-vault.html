Azure Key Vault

Azure

Centrally manage secrets, encryption keys, and certificates.

Key Vault = A Secure Safe for All Your App's Secrets

Never store database passwords, API keys, or certificates in your code or environment variables in Kubernetes manifests. Key Vault stores them securely and your app retrieves them at runtime using its Managed Identity — no hardcoded credentials anywhere. The AKS Secret Store CSI Driver can even mount Key Vault secrets directly as files or Kubernetes secrets.

Store and Retrieve Secrets

# Create Key Vault
az keyvault create \
  --name myapp-vault \
  --resource-group myapp-rg \
  --location eastus \
  --sku standard

# Store a secret
az keyvault secret set \
  --vault-name myapp-vault \
  --name "db-password" \
  --value "Str0ngP@ssword!"

# Retrieve (for testing)
az keyvault secret show \
  --vault-name myapp-vault \
  --name "db-password" \
  --query value -o tsv
// .NET 8 — integrate Key Vault with configuration
builder.Configuration.AddAzureKeyVault(
    new Uri("https://myapp-vault.vault.azure.net/"),
    new DefaultAzureCredential());

// Secrets available as configuration values
var dbPassword = builder.Configuration["db-password"];

Mount Secrets as Kubernetes Files (CSI Driver)

# Install Azure Key Vault Secret Store CSI Driver
az aks enable-addons \
  --addons azure-keyvault-secrets-provider \
  --name myapp-cluster \
  --resource-group myapp-rg
apiVersion: secrets-store.csi.x-k8s.io/v1
kind: SecretProviderClass
metadata:
  name: myapp-secrets
spec:
  provider: azure
  parameters:
    usePodIdentity: "false"
    clientID: <managed-identity-client-id>
    keyvaultName: myapp-vault
    tenantId: <tenant-id>
    objects: |
      array:
      - |
        objectName: db-password
        objectType: secret
