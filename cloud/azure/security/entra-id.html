Microsoft Entra ID

Azure

Cloud identity platform — authentication, authorization, and managed identity.

Entra ID = Azure Active Directory (Renamed)

Microsoft renamed Azure Active Directory to Entra ID in 2023 — same product, new name. It's Microsoft's cloud identity platform used by 500,000+ organizations. For DevOps, the key feature is Managed Identity — your AKS pods, App Service apps, and Azure Functions get an identity automatically (no credentials to manage), and you grant that identity permissions to Azure resources (Key Vault, SQL, Storage).

Managed Identity Types

🤖

System-Assigned

Tied to a specific Azure resource (e.g., AKS cluster). Deleted automatically when the resource is deleted. Simple but less flexible.

👤

User-Assigned

Created independently and assigned to one or more resources. Reusable, survives resource deletion. Best practice for most scenarios.

Grant Key Vault Access to AKS Pod

# Create user-assigned managed identity
az identity create --name myapp-identity --resource-group myapp-rg

# Grant access to Key Vault
az keyvault set-policy \
  --name myapp-vault \
  --object-id $(az identity show --name myapp-identity -g myapp-rg --query principalId -o tsv) \
  --secret-permissions get list

# Link to Kubernetes Service Account (Workload Identity)
az identity federated-credential create \
  --name myapp-fedcred \
  --identity-name myapp-identity \
  --resource-group myapp-rg \
  --issuer "$(az aks show -g myapp-rg -n myapp-cluster --query oidcIssuerProfile.issuerUrl -o tsv)" \
  --subject "system:serviceaccount:production:myapp-sa"

RBAC in Azure

Azure uses RBAC (Role-Based Access Control) for authorization. Assign built-in roles or create custom ones:

# Assign 'Storage Blob Data Contributor' to managed identity
az role assignment create \
  --assignee $(az identity show --name myapp-identity -g myapp-rg --query principalId -o tsv) \
  --role "Storage Blob Data Contributor" \
  --scope /subscriptions/{sub-id}/resourceGroups/myapp-rg/providers/Microsoft.Storage/storageAccounts/myappstorage
