Azure Compute

Azure

AKS and Container Apps — run containerized workloads on Microsoft Azure.

Azure Compute = Where Your Code Runs on Microsoft's Infrastructure

Azure offers multiple ways to run containers: AKS (Azure Kubernetes Service) for complex microservices, Container Apps for serverless containers with KEDA autoscaling, and App Service for traditional web apps. Most cloud-native teams use AKS for production workloads and Container Apps for lightweight, event-driven services.

Azure Container Compute Options
⚙️ AKS
Full Kubernetes. Best for complex microservices.
📦 Container Apps
Serverless containers. KEDA scaling.
🌐 App Service
PaaS for web apps. Simpler than K8s.
⚡ Azure Functions
Event-driven serverless functions.

AKS

Azure Kubernetes Service — managed Kubernetes with Entra ID integration, Key Vault secrets, and Azure Monitor.

Container Apps

Serverless containers with KEDA autoscaling. Scale to zero, run microservices without managing nodes or Kubernetes.
