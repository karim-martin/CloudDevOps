Azure Cloud Services

Microsoft Azure

Microsoft's cloud platform — deeply integrated with Windows, .NET, and enterprise Microsoft tools.

New to Azure?

Microsoft Azure is the second-largest cloud provider. It has the strongest integration with Microsoft products — Active Directory, SQL Server, Visual Studio, and .NET. If your company already uses Microsoft 365, Teams, or Windows Server, Azure is the natural fit. New accounts get $200 in free credits for 30 days plus 12 months of free services.

Compute

Run containerized and serverless workloads on Azure's global infrastructure.

AKS

Azure Kubernetes Service — managed Kubernetes with deep integration into Azure AD, Key Vault, and Azure Monitor.

Container Apps

Serverless containers built on Kubernetes and KEDA. Scale to zero, run microservices without managing nodes.

Databases

Fully managed database services with enterprise-grade reliability.

Azure SQL

Managed SQL Server (fully compatible with on-prem SQL Server). Auto-scaling, built-in HA, and intelligent performance tuning.

Cosmos DB

Globally distributed multi-model database. Supports SQL, MongoDB, Cassandra, and Gremlin APIs with single-digit ms latency worldwide.

Azure Cache for Redis

Managed Redis cache. Speed up database-heavy apps by caching frequently-read data in memory.

Storage

Massively scalable storage for any type of data.

Blob Storage

Object storage for unstructured data — images, videos, backups, and logs. Tiered storage reduces cost for infrequently accessed data.

Azure Container Registry

Private Docker registry. Store, manage, and deploy container images integrated with AKS and Azure Pipelines.

Networking

Secure, high-performance networking for Azure applications.

VNet

Azure Virtual Network — your private network in Azure. Subnets, Network Security Groups, and private endpoints for secure communication.

Load Balancer & App Gateway

Azure Load Balancer (L4) and Application Gateway (L7/WAF). App Gateway is the typical choice for AKS Ingress with HTTPS.

CDN / Front Door

Azure CDN caches content at edge. Azure Front Door adds global load balancing, WAF, and URL-based routing in one service.

Azure DNS

Host your DNS zones in Azure. 100% SLA, anycast routing, and seamless integration with other Azure services.

Security

Enterprise identity management, secrets, and threat protection.

Entra ID (Azure AD)

Microsoft's cloud identity platform. Single sign-on, MFA, conditional access, and workload identity for AKS pods.

Key Vault

Centrally store secrets, keys, and certificates. Applications retrieve them at runtime via managed identity — no hardcoded credentials.

DDoS Protection

Azure's always-on DDoS mitigation. Standard tier provides adaptive tuning, attack telemetry, and SLA guarantees.

DevOps

Microsoft's comprehensive DevOps platform — tightly integrated with Azure services.

Azure Pipelines

Multi-platform CI/CD — build on Linux, Mac, Windows. Supports any language, deploys to any target including AKS and Azure.

Azure DevOps

Full DevOps suite — Boards (project tracking), Repos (Git), Pipelines, Test Plans, and Artifacts. One platform for your whole team.

Observability

Monitor, log, and alert on Azure workloads in real time.

Azure Monitor

Collect metrics and logs from Azure resources, apps, and infrastructure. Set alerts and auto-scale rules based on any metric.

Log Analytics

Centralized log storage and query engine (KQL). Used by Azure Monitor, Defender, and Sentinel for security and operational analysis.
