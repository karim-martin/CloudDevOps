Azure DNS

Azure

Host your DNS zones in Azure with 100% availability SLA.

Azure DNS Hosts Your Domain Records

Azure DNS hosts your DNS zones — the database of records that maps your domain names (myapp.com) to IP addresses or Azure resource endpoints. Azure DNS is backed by the global Azure anycast network with 100% availability SLA. You can also use Private DNS Zones for internal name resolution within your VNet — so your AKS pods can reach mydb.private.example.com instead of a raw IP.

Create DNS Zone and Records

# Create public DNS zone
az network dns zone create \
  --name myapp.example.com \
  --resource-group myapp-rg

# Add A record pointing to Front Door
az network dns record-set a add-record \
  --zone-name myapp.example.com \
  --resource-group myapp-rg \
  --record-set-name "@" \
  --ipv4-address 1.2.3.4

# Or use ALIAS record for Front Door/Traffic Manager
az network dns record-set a create \
  --zone-name myapp.example.com \
  --resource-group myapp-rg \
  --name "@" \
  --target-resource $(az cdn endpoint show --name myapp-endpoint --profile-name myapp-frontdoor --resource-group myapp-rg --query id -o tsv)

Private DNS for AKS

resource "azurerm_private_dns_zone" "sql" {
  name                = "privatelink.database.windows.net"
  resource_group_name = azurerm_resource_group.main.name
}

resource "azurerm_private_dns_zone_virtual_network_link" "sql" {
  name                  = "sql-vnet-link"
  resource_group_name   = azurerm_resource_group.main.name
  private_dns_zone_name = azurerm_private_dns_zone.sql.name
  virtual_network_id    = azurerm_virtual_network.main.id
}

# AKS pods now resolve myapp-sql.database.windows.net
# to private IP via private endpoint
