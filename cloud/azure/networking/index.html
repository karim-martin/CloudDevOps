Azure Networking

Azure

VNet, Load Balancer, Azure Front Door CDN, and Azure DNS.

Azure Networking = Your Private Data Center in Microsoft's Cloud

Every Azure resource lives inside a Virtual Network (VNet). VNets contain subnets — public (internet-facing) and private (internal only). The Application Gateway or Azure Load Balancer handles inbound HTTP(S) traffic. Azure Front Door adds global CDN and WAF at the edge. Azure DNS manages your domain records.

VNet

Virtual Network — your private network in Azure. Subnets, NSGs, private endpoints, and VNet peering.

Load Balancer & App Gateway

Azure Load Balancer (L4) for TCP/UDP. Application Gateway (L7) for HTTP/HTTPS with WAF and AKS Ingress.

CDN / Front Door

Azure Front Door combines global CDN, WAF, and load balancing. Serve static content fast worldwide.

Azure DNS

Host DNS zones in Azure. 100% SLA, global anycast. Integrate with Traffic Manager for intelligent routing.
