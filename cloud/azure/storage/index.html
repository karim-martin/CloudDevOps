Azure Storage

Azure

Blob Storage and Azure Container Registry for Azure applications.

Azure Storage = Files and Images in the Cloud

Blob Storage stores any kind of unstructured file — images, videos, documents, backups — at massive scale with 16 nines of durability. Azure Container Registry (ACR) stores Docker container images, integrated with AKS for seamless deployments.

Blob Storage

Object storage for any file. Host static websites, store user uploads, and archive data at very low cost.

Azure Container Registry

Private Docker registry. Build, store, and manage container images with geo-replication and vulnerability scanning.
