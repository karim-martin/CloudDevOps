Azure Blob Storage

Azure

Massively scalable object storage for any type of unstructured data.

Blob Storage = Infinitely Scalable File Storage

Azure Blob Storage stores files as 'blobs' in 'containers' (not Docker containers — think of them as folders). It's similar to AWS S3 and GCP Cloud Storage. Azure Storage accounts have 16 nines of durability and automatically store 3 copies of your data by default (LRS — Locally Redundant Storage). Enable GRS and your data is replicated to a second Azure region 400+ miles away.

Storage Access Tiers

TierUse CaseAccess LatencyCost
HotFrequently accessed dataMillisecondsHigher storage, low access

Upload and Manage Blobs

# Azure CLI — upload a file
az storage blob upload \
  --account-name myappstorage \
  --container-name uploads \
  --name photos/photo.jpg \
  --file ./photo.jpg \
  --auth-mode login

# Generate SAS URL for client-side upload (1 hour)
az storage blob generate-sas \
  --account-name myappstorage \
  --container-name uploads \
  --name photos/photo.jpg \
  --permissions rw \
  --expiry $(date -u -d '1 hour' '+%Y-%m-%dT%H:%MZ')
// .NET SDK — upload from stream
var credential = new DefaultAzureCredential();  // Workload Identity
var blobClient = new BlobClient(
    new Uri("https://myappstorage.blob.core.windows.net/uploads/photo.jpg"),
    credential);

await blobClient.UploadAsync(fileStream, overwrite: true);
