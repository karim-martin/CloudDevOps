Azure Container Registry

Azure

Private Docker container registry for Azure deployments.

ACR = Your Private Docker Hub on Azure

When you build a Docker image and want AKS to run it, you need somewhere to store it. ACR is Azure's private container registry. AKS can pull images from ACR using a Managed Identity — no credentials needed. You can also build images directly in ACR using ACR Tasks (similar to CodeBuild/Cloud Build).

Create ACR and Push Images

# Create container registry
az acr create \
  --name myappcr \
  --resource-group myapp-rg \
  --sku Standard \
  --admin-enabled false

# Login with Docker
az acr login --name myappcr

# Build and push
docker build -t myappcr.azurecr.io/api:v1.0 .
docker push myappcr.azurecr.io/api:v1.0

# Or build directly in ACR (no local Docker needed)
az acr build \
  --registry myappcr \
  --image api:v1.0 \
  --file Dockerfile \
  .

Attach ACR to AKS

# Grant AKS pull permission from ACR (managed identity)
az aks update \
  --name myapp-cluster \
  --resource-group myapp-rg \
  --attach-acr myappcr

# Now use ACR images in deployments — no imagePullSecrets needed!
# image: myappcr.azurecr.io/api:v1.0

ACR Tasks — Build in the Cloud

# Trigger a build on every git commit
az acr task create \
  --name build-api \
  --registry myappcr \
  --image "api:{{.Run.ID}}" \
  --context "https://github.com/myorg/myapp#main" \
  --file Dockerfile \
  --git-access-token $GITHUB_TOKEN
