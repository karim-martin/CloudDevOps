Amazon Route 53

AWS

Scalable DNS service with health checks and intelligent routing.

DNS = The Internet's Phone Book

When you type myapp.com in a browser, DNS translates that to an IP address your computer can connect to. Route 53 is AWS's DNS service. You create a Hosted Zone for your domain, then add records: an A record points to an IP, a CNAME points to another domain name, an ALIAS record (AWS-specific) points to a CloudFront or ALB DNS name.

Common DNS Records

Record TypeUse CaseExample
ADomain → IPv4 addressmyapp.com → 1.2.3.4
AAAADomain → IPv6 addressmyapp.com → 2001:db8::1
CNAMEDomain → another domainwww.myapp.com → myapp.com
ALIASDomain → AWS resource (no TTL charge)myapp.com → alb.us-east-1.amazonaws.com
MXEmail routingmyapp.com → mail.google.com
TXTDomain verification, SPF/DKIMmyapp.com → "v=spf1 include:..."

Point Domain to CloudFront

resource "aws_route53_record" "apex" {
  zone_id = aws_route53_zone.main.zone_id
  name    = "myapp.com"
  type    = "A"

  alias {
    name                   = aws_cloudfront_distribution.frontend.domain_name
    zone_id                = aws_cloudfront_distribution.frontend.hosted_zone_id
    evaluate_target_health = false
  }
}

Health Checks + Failover

Route 53 can check if your endpoint is healthy (HTTP 200) and automatically route traffic to a backup region if the primary fails. This is multi-region active-passive failover.

resource "aws_route53_health_check" "primary" {
  fqdn              = "primary.myapp.com"
  port              = 443
  type              = "HTTPS"
  resource_path     = "/health"
  failure_threshold = 3
  request_interval  = 30
}
