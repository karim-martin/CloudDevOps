AWS Networking

AWS

VPC, load balancers, CloudFront CDN, and Route 53 DNS on AWS.

Cloud Networking in Plain English

Every resource in AWS runs inside a VPC (Virtual Private Cloud) — your isolated network. Within the VPC you have subnets (public ones can reach the internet, private ones can't). A Load Balancer receives traffic from the internet and distributes it to your containers. CloudFront caches your content at edge locations worldwide for speed. Route 53 translates domain names (myapp.com) to IP addresses.
