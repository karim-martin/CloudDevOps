Amazon CloudFront

AWS

AWS CDN — deliver content fast from 600+ edge locations worldwide.

A CDN Puts Your Content Close to Every User

Without a CDN, every user — whether in Tokyo, London, or São Paulo — downloads your site's files from your single server in, say, us-east-1. That means 200ms latency for distant users. CloudFront caches your content at 600+ edge locations worldwide. A user in Tokyo gets files from a Tokyo edge server — 10× faster. CloudFront also provides DDoS protection and can be paired with WAF to block malicious traffic.

Common Use Cases

⚛️

React / SPA Hosting

Store your React build in S3, put CloudFront in front. Globally distributed static site, no servers needed. Configure to return index.html for all paths (SPA routing).

🎥

Media Streaming

Distribute video, images, and downloads with automatic compression and adaptive bitrate streaming. Pay only for data transferred to users.

🔄

API Acceleration

Cache API responses at the edge. Non-personalized responses (product catalog, prices) can be cached for seconds, reducing ALB and EC2 load dramatically.

🛡️

DDoS + WAF

All CloudFront distributions get AWS Shield Standard (DDoS) for free. Add WAF for SQL injection, XSS, and bot protection at the edge.

CloudFront + S3 + React (Terraform)

resource "aws_cloudfront_distribution" "frontend" {
  origin {
    domain_name = aws_s3_bucket.frontend.bucket_regional_domain_name
    origin_id   = "S3-frontend"

    s3_origin_config {
      origin_access_identity = aws_cloudfront_origin_access_identity.oai.cloudfront_access_identity_path
    }
  }

  enabled             = true
  default_root_object = "index.html"
  aliases             = ["myapp.com", "www.myapp.com"]

  default_cache_behavior {
    allowed_methods  = ["GET", "HEAD"]
    cached_methods   = ["GET", "HEAD"]
    target_origin_id = "S3-frontend"
    compress         = true
    viewer_protocol_policy = "redirect-to-https"
  }

  # Return index.html for React router 404s
  custom_error_response {
    error_code         = 404
    response_code      = 200
    response_page_path = "/index.html"
  }

  viewer_certificate {
    acm_certificate_arn = aws_acm_certificate.cert.arn
    ssl_support_method  = "sni-only"
  }
}
