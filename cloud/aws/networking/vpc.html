AWS VPC

AWS

Virtual Private Cloud — your isolated network inside AWS.

A VPC is Like Your Office Building's Private Network

Before cloud, companies had physical networks — cables, switches, private IP ranges. A VPC gives you the same thing, virtually. All your AWS resources (EC2, RDS, EKS) live inside a VPC. Public subnets can reach the internet (via an Internet Gateway). Private subnets cannot — they connect out via a NAT Gateway (outbound only). Your databases should always be in private subnets.

VPC Architecture for EKS

VPC: 10.0.0.0/16
├── Public Subnets (3 AZs)          ← Load Balancers, NAT Gateways
│   ├── 10.0.1.0/24  (us-east-1a)
│   ├── 10.0.2.0/24  (us-east-1b)
│   └── 10.0.3.0/24  (us-east-1c)
├── Private Subnets (3 AZs)         ← EKS Nodes (worker pods)
│   ├── 10.0.11.0/24 (us-east-1a)
│   ├── 10.0.12.0/24 (us-east-1b)
│   └── 10.0.13.0/24 (us-east-1c)
└── Database Subnets (3 AZs)        ← RDS, ElastiCache
    ├── 10.0.21.0/24 (us-east-1a)
    ├── 10.0.22.0/24 (us-east-1b)
    └── 10.0.23.0/24 (us-east-1c)

Key Components

🌐

Internet Gateway

Attached to the VPC. Allows resources in public subnets to send/receive traffic from the internet.

🔄

NAT Gateway

In public subnet. Allows private subnet resources to make outbound internet requests (e.g., pull Docker images, call APIs) without being reachable from the internet.

🛡️

Security Groups

Stateful firewall for EC2/RDS/EKS. Define which ports/IPs are allowed inbound/outbound. Best practice: allow only what's needed.

🔒

PrivateLink / VPC Endpoints

Access AWS services (S3, Secrets Manager) from private subnets without traffic leaving AWS — faster and more secure than via NAT Gateway.

Create VPC with Terraform

module "vpc" {
  source  = "terraform-aws-modules/vpc/aws"
  version = "5.x"

  name = "myapp-vpc"
  cidr = "10.0.0.0/16"

  azs             = ["us-east-1a", "us-east-1b", "us-east-1c"]
  public_subnets  = ["10.0.1.0/24", "10.0.2.0/24", "10.0.3.0/24"]
  private_subnets = ["10.0.11.0/24", "10.0.12.0/24", "10.0.13.0/24"]

  enable_nat_gateway = true
  single_nat_gateway = false  # One per AZ for HA

  # Required tags for EKS subnet discovery
  public_subnet_tags = {
    "kubernetes.io/role/elb" = "1"
  }
  private_subnet_tags = {
    "kubernetes.io/role/internal-elb" = "1"
  }
}
