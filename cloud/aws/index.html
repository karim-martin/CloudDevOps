AWS Cloud Services

Amazon Web Services

The world's most widely used cloud platform with the broadest service selection.

New to AWS?

Amazon Web Services (AWS) launched in 2006 and is the largest cloud provider by market share. It offers 200+ services covering everything from virtual machines to AI. AWS is widely used in startups and enterprises alike. New accounts get a 12-month free tier with generous limits for core services like EC2, S3, and RDS.

Compute

Run containers, functions, and virtual machines on AWS global infrastructure.

EKS

Elastic Kubernetes Service — managed Kubernetes. Run Kubernetes workloads without managing the control plane.

Fargate & Lambda

Serverless compute. Fargate runs containers without managing EC2 nodes. Lambda runs code in response to events.

Databases

Managed database services for every data model — relational, NoSQL, and in-memory caching.

RDS

Relational Database Service — managed MySQL, PostgreSQL, MariaDB, Oracle, and SQL Server with Multi-AZ failover.

DynamoDB

Serverless NoSQL key-value and document database. Single-digit millisecond latency at any scale.

ElastiCache

Managed Redis and Memcached. Cache database query results, session data, and hot objects for speed.

Storage

Industry-standard object storage and container registries.

S3

Simple Storage Service — store any file, any size, with 99.999999999% durability. The backbone of cloud storage.

ECR

Elastic Container Registry — private Docker registry deeply integrated with EKS and Fargate.

Networking

Secure, scalable networking for cloud applications.

VPC

Virtual Private Cloud — your isolated network inside AWS. Control subnets, routing, security groups, and internet access.

ALB / NLB

Application Load Balancer (HTTP/HTTPS routing) and Network Load Balancer (ultra-low latency TCP/UDP). Used with EKS Ingress.

CloudFront

AWS CDN with 600+ edge locations worldwide. Serve static assets, APIs, and video from the nearest point to your user.

Route 53

Highly available DNS service. Register domains, route traffic, and set up health-check-based failover.

Security

Identity management, secrets storage, and threat protection.

IAM

Identity and Access Management — control who and what can access AWS resources. Includes IRSA for Kubernetes pod-level auth.

Secrets Manager

Store and automatically rotate database credentials, API keys, and certificates. Apps retrieve secrets at runtime.

WAF & Shield

Web Application Firewall blocks SQL injection, XSS, and bot traffic. Shield provides DDoS protection at no extra cost.

DevOps

AWS developer tools for continuous integration and delivery.

CodePipeline

Visual CI/CD pipeline orchestration. Connect source (GitHub), build (CodeBuild), test, and deploy stages.

CodeBuild

Managed build service — compile code, run tests, build Docker images, and push to ECR without managing servers.

Observability

Monitor and troubleshoot your AWS workloads.

CloudWatch

Unified observability — collect metrics, logs, and traces. Set alarms, build dashboards, and auto-scale based on metrics.

X-Ray

Distributed tracing service. Visualize request flows across microservices to find bottlenecks and errors.
