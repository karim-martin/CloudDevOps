Amazon CloudWatch

AWS

Metrics, logs, alarms, and dashboards for AWS services.

CloudWatch is Your App's Health Monitor

AWS services automatically send metrics to CloudWatch — your EKS nodes' CPU usage, RDS connections, ALB request count, etc. You can also send custom metrics from your app. Set Alarms that notify you (via SNS → email/Slack) when something is wrong. Create Dashboards to visualize key metrics at a glance. CloudWatch Logs stores all your application logs in a searchable, queryable format.

Key CloudWatch Features

📊

Metrics

Thousands of built-in AWS metrics. Send custom metrics from your app with PutMetricData. Resolution from 1-second to 1-hour.

🚨

Alarms

Alert when a metric exceeds a threshold. Trigger SNS notifications, Lambda functions, or EC2/ASG actions automatically.

📝

Logs Insights

Query logs with SQL-like syntax. Find all errors in the last hour across all pods. Aggregate, filter, and visualize log patterns.

🗺️

Container Insights

Enhanced monitoring for EKS/ECS. Pod-level CPU, memory, network metrics. View performance by cluster, node, pod, or container.

Enable Container Insights for EKS

aws eks create-addon \
  --cluster-name my-cluster \
  --addon-name amazon-cloudwatch-observability \
  --service-account-role-arn arn:aws:iam::123:role/CWAgentRole

CloudWatch Logs Insights Query

# Find all 5xx errors in the last hour
fields @timestamp, @message
| filter @message like /ERROR/ or @message like /5[0-9][0-9]/
| sort @timestamp desc
| limit 100

# Count errors per minute
fields @timestamp, @message
| filter @message like /ERROR/
| stats count(*) as errorCount by bin(1m)
| sort @timestamp asc

Create an Alarm (Terraform)

resource "aws_cloudwatch_metric_alarm" "high_error_rate" {
  alarm_name          = "myapp-high-error-rate"
  comparison_operator = "GreaterThanThreshold"
  evaluation_periods  = 2
  metric_name         = "HTTPCode_Target_5XX_Count"
  namespace           = "AWS/ApplicationELB"
  period              = 60  # 1 minute
  statistic           = "Sum"
  threshold           = 10
  alarm_description   = "More than 10 5xx errors per minute"
  alarm_actions       = [aws_sns_topic.alerts.arn]

  dimensions = {
    LoadBalancer = aws_lb.main.arn_suffix
  }
}
