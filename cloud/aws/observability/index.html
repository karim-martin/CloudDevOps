AWS Observability

AWS

CloudWatch and X-Ray — monitor, log, and trace your AWS workloads.

Observability = Knowing What Your App is Doing

The three pillars of observability are: Metrics (numbers over time — CPU usage, request count, error rate), Logs (text records of events — errors, warnings, info), and Traces (the path a request took through your services — how long each step took). CloudWatch handles metrics and logs. X-Ray handles distributed tracing.

CloudWatch

Unified observability platform. Collect metrics, logs, and traces. Create dashboards, set alarms, and auto-scale based on any metric.

X-Ray

Distributed tracing. Visualize how requests flow through your microservices. Identify latency hotspots and error sources.
