AWS Storage

AWS

Object storage and container registries on Amazon Web Services.

Types of Storage in the Cloud

Object Storage (S3) — store files as-is: images, videos, backups, logs. No file system, no folders (just key-value pairs). Unlimited capacity. Perfect for static assets and user uploads. Container Registry (ECR) — store Docker images. When Kubernetes needs to pull your app's Docker image, it pulls it from ECR.

S3

Simple Storage Service. Store unlimited files with 11 nines of durability. Serve static websites, user uploads, backups, and ML datasets.

ECR

Elastic Container Registry. Private Docker image registry integrated with EKS, Fargate, and CodeBuild.
