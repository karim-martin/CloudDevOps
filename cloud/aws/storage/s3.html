Amazon S3

AWS

Infinitely scalable object storage — the foundation of cloud storage.

S3 is Like Google Drive — But for Your App

S3 stores files as objects in buckets. An object is a file + metadata. A bucket is a container for objects. There's no folder structure (just key prefixes like images/2024/photo.jpg). S3 is designed for 11 nines of durability (99.999999999%) — if you store 10 million files, you'd expect to lose one every 10,000 years.

Common Use Cases

🖼️

Static Asset Hosting

Host your React/Vue app's built files on S3 + CloudFront. Scale to millions of users with no servers.

📤

User File Uploads

Generate pre-signed URLs so users upload directly to S3 from their browser — bypassing your servers entirely.

💾

Database Backups

Export RDS snapshots to S3. Store application logs. Archive data to S3 Glacier for pennies per GB/month.

🔄

Data Lake / ML

Store raw data in S3, process with Athena (SQL) or SageMaker. The foundation of every AWS data platform.

CLI Operations

# Create a bucket
aws s3 mb s3://my-app-uploads --region us-east-1

# Upload a file
aws s3 cp ./photo.jpg s3://my-app-uploads/photos/photo.jpg

# Sync a local folder to S3 (deploy React build)
aws s3 sync ./build/ s3://my-app-static/ --delete

# Generate a pre-signed URL (expires in 1 hour)
aws s3 presign s3://my-app-uploads/photos/photo.jpg --expires-in 3600

# Enable versioning
aws s3api put-bucket-versioning \
  --bucket my-app-uploads \
  --versioning-configuration Status=Enabled
