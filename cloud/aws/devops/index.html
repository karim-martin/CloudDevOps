AWS DevOps

AWS

CI/CD with CodePipeline and CodeBuild on Amazon Web Services.

CI/CD = Automating the Path from Code to Production

CI (Continuous Integration) means every code commit is automatically built and tested. CD (Continuous Delivery/Deployment) means passing builds are automatically deployed to staging or production. AWS CodePipeline orchestrates the flow: Source (GitHub) → Build (CodeBuild) → Test → Deploy (to EKS). This replaces manual deployment steps and catches bugs before they reach users.

AWS CI/CD Pipeline Flow
👨‍💻 Developer
git push to main
📋 CodePipeline
Orchestrates the pipeline
🔨 CodeBuild
Build + Test + Docker push to ECR
→
🚀 Deploy to EKS
kubectl apply / Helm upgrade

CodePipeline

Visual pipeline orchestration. Connects source, build, test, and deploy stages with approval gates.

CodeBuild

Managed build environment. Run tests, build Docker images, and push to ECR without managing servers.
GitHub Actions Alternative

Many teams use GitHub Actions instead of AWS CodePipeline — it's simpler and works with any cloud. See the DevOps section for GitHub Actions CI/CD guides. Both approaches work well with EKS.
