AWS CodePipeline

AWS

Fully managed CI/CD pipeline orchestration service.

CodePipeline is the Conductor

CodePipeline itself doesn't build or deploy anything — it coordinates other services. It connects your source code repo (GitHub, CodeCommit), triggers a CodeBuild job to build and test, optionally requires a manual approval, then deploys to EKS or Elastic Beanstalk. Think of it as a workflow engine that knows what to run and when, reacting to code changes automatically.

Pipeline Stages

# cloudformation/pipeline.yaml (simplified)
Pipeline:
  Type: AWS::CodePipeline::Pipeline
  Properties:
    Stages:
      # Stage 1: Source — pull from GitHub on push
      - Name: Source
        Actions:
          - Name: GitHub
            ActionTypeId: {Category: Source, Owner: ThirdParty, Provider: GitHub, Version: 1}
            Configuration:
              Owner: myorg
              Repo: myapp
              Branch: main
              OAuthToken: !Ref GitHubToken

      # Stage 2: Build — run CodeBuild
      - Name: Build
        Actions:
          - Name: BuildAndTest
            ActionTypeId: {Category: Build, Owner: AWS, Provider: CodeBuild, Version: 1}
            Configuration:
              ProjectName: !Ref CodeBuildProject

      # Stage 3: Manual approval (optional)
      - Name: Approval
        Actions:
          - Name: ManualApproval
            ActionTypeId: {Category: Approval, Owner: AWS, Provider: Manual, Version: 1}

      # Stage 4: Deploy to EKS
      - Name: Deploy
        Actions:
          - Name: DeployToEKS
            ActionTypeId: {Category: Build, Owner: AWS, Provider: CodeBuild, Version: 1}
            Configuration:
              ProjectName: !Ref DeployProject

Typical buildspec.yml

# buildspec.yml — runs in CodeBuild
version: 0.2
phases:
  pre_build:
    commands:
      - aws ecr get-login-password | docker login --username AWS --password-stdin $ECR_URI
  build:
    commands:
      - docker build -t $ECR_URI/myapp:$CODEBUILD_RESOLVED_SOURCE_VERSION .
      - docker push $ECR_URI/myapp:$CODEBUILD_RESOLVED_SOURCE_VERSION
  post_build:
    commands:
      - aws eks update-kubeconfig --name my-cluster --region us-east-1
      - kubectl set image deployment/my-app app=$ECR_URI/myapp:$CODEBUILD_RESOLVED_SOURCE_VERSION
