GCP Cloud Services

Google Cloud

Google Cloud Platform services for containerized workloads.

New to GCP?

Google Cloud Platform (GCP) is Google's suite of cloud services. GCP is famous for its Kubernetes engine (GKE — Google literally created Kubernetes), its data analytics tools like BigQuery, and cutting-edge AI/ML APIs. Most of GCP's services have a generous free tier and new accounts get $300 in credits.

Compute

Run containers and serverless workloads on Google's global infrastructure.

GKE

Google Kubernetes Engine — managed Kubernetes from the creators of Kubernetes. Autopilot mode removes all node management overhead.

Cloud Run

Deploy containers without managing servers. Scales to zero when idle (you pay nothing when not in use).

Databases

Fully managed databases — GCP handles backups, patches, and failover automatically.

Cloud SQL

Managed MySQL, PostgreSQL, and SQL Server with automatic backups and high availability.

Firestore

Serverless NoSQL document database. Real-time sync, offline support, and global scale.

Memorystore

Managed Redis and Memcached for sub-millisecond caching. Dramatically speeds up database-heavy apps.

Storage

Scalable storage for files, images, container images, and build artifacts.

Cloud Storage

Object storage for any file type. Store backups, user uploads, static assets, and logs.

Artifact Registry

Private registry for Docker container images and language packages (npm, Maven, PyPI).

Networking

Global networking infrastructure — VPC, load balancers, CDN, and DNS.

VPC

Virtual Private Cloud — a private network inside GCP. Isolate resources and control traffic flow.

Load Balancing

Global HTTP(S) load balancer. Distributes traffic across regions and handles SSL termination.

Cloud CDN

Cache content at edge nodes worldwide for fast delivery to users regardless of location.

Cloud DNS

100% uptime SLA DNS service. Manage domain records for your applications.

Security

Identity management, secrets, and application protection.

IAM

Control who can do what across all GCP services. Includes Workload Identity for keyless auth.

Secret Manager

Store API keys, passwords, and certificates securely. Apps fetch secrets at runtime — no hardcoded credentials.

Cloud Armor

DDoS protection and Web Application Firewall (WAF). Block malicious traffic at Google's edge.

DevOps

CI/CD services to automate building, testing, and deploying your applications.

Cloud Build

Serverless CI/CD. Build Docker images, run tests, and push to Artifact Registry automatically.

Cloud Deploy

Managed continuous delivery to GKE and Cloud Run with approval gates and rollback.

Observability

Monitor, log, and alert on your applications running on GCP.

Cloud Monitoring

Metrics, dashboards, and alerting for GCP services and custom application metrics.

Cloud Logging

Centralized log ingestion, search, and analysis. All GCP services write logs here automatically.
